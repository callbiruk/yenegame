# YeneGame site

Static pages for [YeneGame](https://callbiruk.github.io/yenegame/) and the YeneCharades app,
hosted on GitHub Pages and linked from inside the app.

| Page | URL |
| --- | --- |
| About | https://callbiruk.github.io/yenegame/ |
| Privacy Policy | https://callbiruk.github.io/yenegame/privacy/ |
| Terms of Use | https://callbiruk.github.io/yenegame/terms/ |
| Support & FAQ | https://callbiruk.github.io/yenegame/support/ |
| Delete your data | https://callbiruk.github.io/yenegame/delete-data/ |

Plain HTML and one stylesheet (`style.css`). No build step, no scripts, no trackers.
Edit the `index.html` in each folder and push to `main`; Pages redeploys automatically.
