# YeneGame site

Static pages for [YeneGame](https://yenegame.github.io/) and the YeneCharades app,
hosted on GitHub Pages and linked from inside the app.

| Page | URL |
| --- | --- |
| About | https://yenegame.github.io/ |
| Privacy Policy | https://yenegame.github.io/privacy/ |
| Terms of Use | https://yenegame.github.io/terms/ |
| Support & FAQ | https://yenegame.github.io/support/ |
| Delete your data | https://yenegame.github.io/delete-data/ |

Plain HTML and one stylesheet (`style.css`). No build step, no scripts, no trackers.
Edit the `index.html` in each folder and push to `main`; Pages redeploys automatically.
